# Slope Is a Rate

Math 2201 (Unit 6, Section 1, Proportional Reasoning) formative practice app. Indicators 6.15, 6.18, 6.19.

Students read generated segmented distance-time and process graphs, compute the rate of a chosen segment with units, identify the fastest segment and any stopped segment, and adjust a line's steepness to match a stated rate. A draw mode has them plot the segmented graph for a described trip (by clicking the grid or by keyboard entry) and then compares their graph against a model, leg by leg. A printable graph analysis sheet collects the segments, the student's rates, and their fastest and stopped picks for the portfolio.

Fresh generated graphs on every round; segment rates are always clean values. Single-file HTML, no external dependencies, no student data leaves the page.
